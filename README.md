# Amazon Dropshipping Formula

A comprehensive, responsive web application designed to help entrepreneurs succeed in Amazon dropshipping business. Built with HTML, CSS, and JavaScript, featuring advanced calculators, product research tools, and analytics dashboard with AED (Dirham) currency support.

## 🚀 Features

### 💰 Profit Calculator
- **Real-time calculations** with AED currency support
- **Comprehensive cost analysis** including:
  - Product costs
  - Shipping expenses
  - Amazon fees (customizable percentage)
  - Advertising spend
  - Quantity calculations
- **Visual profit breakdown** with interactive charts
- **Key metrics display**: ROI, profit margin, net profit
- **Responsive design** for all devices

### 🔍 Product Research Tools
- **Keyword Research**: Find profitable keywords with volume and competition data
- **Trend Analysis**: Analyze market trends by category
- **Product Scorer**: Evaluate product potential with comprehensive scoring system
- **Mock data simulation** for demonstration purposes

### 🏭 Supplier Network
- **Curated supplier database** featuring:
  - AliExpress integration
  - DHgate connections
  - 1688.com access
- **Supplier ratings and statistics**
- **Shipping time estimates**
- **Minimum order quantities**

### 📊 Analytics Dashboard
- **Revenue tracking** with visual charts
- **Profit monitoring** with growth indicators
- **Order statistics** and performance metrics
- **Interactive data visualization**
- **Real-time counter animations**

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)

## 🚀 Getting Started

### Prerequisites

1. **Download** or clone the project files

## 📖 Usage Guide

### Profit Calculator
1. **Navigate** to the Calculator section
2. **Enter** your product details:
   - Product cost in AED
   - Selling price in AED
   - Shipping costs
   - Amazon fees percentage
   - Advertising spend
   - Quantity
3. **View** real-time profit calculations
4. **Analyze** the visual profit breakdown chart

### Product Research
1. **Keyword Research**:
   - Enter a product keyword
   - Click "Search" to get volume and competition data
   
2. **Trend Analysis**:
   - Select a category or leave blank for all
   - Click "Analyze" to see trending products
   
3. **Product Scorer**:
   - Enter an Amazon product URL
   - Get a comprehensive product score

### Supplier Network
- **Browse** available suppliers
- **View** ratings and statistics
- **Compare** shipping times and minimum orders
- **Connect** with preferred suppliers

### Analytics Dashboard
- **Monitor** your business performance
- **Track** revenue and profit trends
- **Analyze** key metrics and growth indicators

## 🔧 Customization

### Modifying Currency
To change from AED to another currency:
1. **Update** the `formatCurrency()` function in `script.js`
2. **Replace** "AED" with your desired currency code
3. **Adjust** currency symbols in HTML if needed

### Adding New Features
The modular code structure allows easy expansion:
- **Add new sections** to `index.html`
- **Style** with additional CSS in `styles.css`
- **Implement functionality** in `script.js`

### Customizing Styling
- **Colors**: Modify CSS custom properties
- **Fonts**: Change Google Fonts imports
